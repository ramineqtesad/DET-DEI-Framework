# DET-DEI-Framework
Computational framework and data for the Disturbed Equilibrium Theory (DET) and Index (DEI). Includes global case studies (Urmia, Aral, Amazon, Reef, Hurricane) with figures, tables, and scripts for ecosystem collapse and renewal.
# Disturbed Equilibrium Theory (DET) & Disturbed Equilibrium Index (DEI)

This repository contains supplementary materials for the DET/DEI framework introduced in:
> Gozarani Eghtesad, R. (2025). The Disturbed Equilibrium Theory (DET) and the Disturbed Equilibrium Index (DEI): A Predictive Framework for Environmental Collapse and Renewal. (Submitted to Springer).

## Contents
- **/Figures**: High-resolution figures used in the article.
- **/Tables**: Data tables (CSV/Excel) with normalized indicators for case studies (Lake Urmia, Aral Sea, Amazon Rainforest, etc.).
- **/Code**: Python/R scripts to calculate the DEI index, including sample Jupyter Notebooks.
- **/Data**: Example datasets (open-access or simulated) used to demonstrate the DEI framework.
